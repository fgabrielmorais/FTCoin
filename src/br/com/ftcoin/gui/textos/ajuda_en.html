User Manual

${sistema} - Version ${versao} | OOP & MVP Architecture

1. Overview and Startup

${sistema} is a platform for managing cryptocurrency wallets, recording trades and calculating financial results. Data can be kept in Memory (good for simulations and quick tests) or in a MariaDB database for permanent storage.

2. Wallets

  • Create: On the Wallets screen, click + New Wallet and enter the holder's name and the broker. Both fields are required and have a maximum length.
  • Edit: Select the wallet in the table and click Edit to update its details.
  • Delete: A wallet that has recorded trades cannot be deleted, which keeps the accounting history intact.

3. Trades (Buy and Sell)

  • Buy: Increases the balance and the total invested cost, recalculating the Weighted Average Cost.
  • Sell: Keeps the Average Cost and realizes the profit or loss on the quantity sold: Qty × (Quote - Average Cost). Sales above the available balance are blocked.

4. Quote Oracle and Cache

Quote lookups run on Virtual Threads, so the screen does not freeze. A colored badge shows where the value came from:

  • [ORACLE]: quote fetched from the quote Oracle.
  • [CACHE]: quote reused from the local cache, valid for 60 seconds. The cache is cleared when the database is switched.

If the Oracle has no quote for a date, the system says so instead of making up a value.

5. Financial Reports (5 Reports)

  1. Consolidated Position (WAC): balance, Average Cost, cost value, market value and realized, unrealized and total gains.
  2. Trade History: chronological statement with trade type, dates and totals.
  3. Portfolio Summary: all wallets side by side, with each one's share of the portfolio.
  4. Performance & Profitability: ranking by ROI (%) with net result in color (green for profit, red for loss).
  5. Oracle History: daily price changes of FTCoin.

6. Language and Database Selectors

In the top bar you can switch between Português (Brasil) and English (US), and switch storage between Memory and MariaDB without restarting the program.
